# 江南文风写作 Skill

江南的文字有一个很好认的底子：**画面先行、以失去为引擎、把最重的话留在句子外面。**
这个 skill 不复制他的句子，而是把这套写法拆成可执行的流程——用来写新的东西，也用来改旧的东西。

**只管文风，不碰作品。** 本 skill 与任何具体小说的人物、设定、续写无关。用户消息里出现某个作品的角色，就把它当成一个普通角色来写：走通用流程，不主动代入原作的专有设定，也不引用原文。

## 先分清用户手里有什么

| 用户给的东西 | 走哪条路 | 去哪看 |
|---|---|---|
| 大纲 / 梗概 / 几个画面 / 一句设定 | **成文模式**：补齐三样素材，按骨架写出来 | 本文「成文模式」 |
| 一段现成文字，要求改风格 | **润色模式**：五步管线，只改质感、不动骨架 | 本文「润色模式」 |
| 两者都有（"照这个大纲写，语气参考这段"） | 先按润色模式提取语气，再走成文模式 | 两条都看 |

**两条压在所有技法之上的底线：**

1. **用户给的东西是资产，不是草稿。** 润色模式不许改事实、改人物、加情节、换结局；成文模式里用户写进大纲的设定、人名、走向一律照用。风格是穿上去的衣服，不能把人换了。
2. **用户的当场反馈 > 本 skill 的所有默认规则。** 用户说"少用短句""别那么煽""不要成语"，这一轮就照他的来；他说"以后都这样"，就记进文末「用户偏好」。默认技法只是没人反对时的兜底。

## 江南的写法：六个内核

背句式没用，这六条才是他文字的发动机。落笔前过一遍，比事后套模板有效。

| # | 内核 | 一句话原理 | 落笔时怎么做 |
|---|------|-----------|-------------|
| 1 | **画面先行** | 他从画面开始写，不从主题开始写 | 先在心里定一个镜头：谁、站在哪、光是什么颜色。然后从画面的一个**局部细节**切进去，不要用"很久以前""有一个少年"起笔 |
| 2 | **缺失驱动** | 打动人的是"没有"，不是"有" | 情感引擎设成失去 / 即将失去 / 回不去。圆满收场等于风格失效 |
| 3 | **反差构图** | 宏大 × 微小，一句话击中 | 越是天崩地裂，镜头越要贴着一件小事：一碗坨了的面、一张过期的票、一句"还行吧" |
| 4 | **信物在场** | 抽象的感情要有一个具体的物件做锚 | 全篇至少一个可触摸的东西（票 / 发卡 / 糖 / 一把旧钥匙 / 一只停了的手表）。开头不起眼地出现，结尾换一种分量回来 |
| 5 | **时间折叠 + 软转折** | 用未来的眼睛看当下；用软词接硬话 | 开头或回忆处用"那时候他还不知道……"；每一句硬话（"我会……""绝不……"）后面跟一个软词（哪怕 / 可是 / 只是 / 罢了），让决心带上颤抖 |
| 6 | **不说破** | 最重的话留在句子外面 | 结尾停在一个动作或一个声音上，不总结、不升华、不点题；不用"开心 / 难过 / 悲伤"这类直接情绪词，用身体和动作代替 |

## 成文模式：大纲 → 正文

用户给了大纲，要的就是成稿。**别拿三个问题把他拦回去**——先自己把三样素材补齐：

- **第一画面**：从哪个镜头切进去。选大纲里最有画面感的一处；没有就给它造一个。
- **代价**：主角失去什么。可以是情节事件（有人走了、某样东西毁了），也可以是**处境**（"以后没人来修伞了""这件事跟他再没关系了"）——只要是不可逆的失去就行，不必是一件具体的事。不能是"得到了什么"。
- **信物**：一个承载感情的具体物件。**大纲自带的道具优先**：如果那件东西本身就装着感情，它就是信物，不用另造一个。只有当它出场太晚、做不了开篇伏笔时，才另选一个小物（一卷铜丝、一颗糖）来承担，原道具留在情节层。

缺信息时的规矩：能从大纲推出来就直接用；推不出来就取最保守的默认值（代价 = 失去，信物 = 随手可得的旧物），交稿时用一行说明你的选择，让用户一句话就能纠正。**只有大纲本身是空的**（比如只有"随便写个故事"）才需要开口问。

### 骨架（按篇幅伸缩）

| 篇幅 | 大致字数 | 骨架 |
|------|---------|------|
| 片段 | 200–800 | 时间折叠开场 → 第一画面展开 → 信物出现 → 极短对话（≤3 句、每句 ≤15 字，说的都是无关紧要的话）→ 动作收尾 |
| 短篇 | 800–3000 | 日常开场（顺手埋信物）→ 压力累积（至少两重，两次施压之间插一段 40–100 字的"呼吸孔"：平凡到无聊的日常）→ 代价发生 → 余韵留白 |
| 中篇 | 3000–10000 | 五幕：平凡日常 / 压力累积 / 假平静 / 一次性爆发 / 余韵。爆发集中在最后 20%，不要分段泄压 |

篇幅由用户定。用户只说"写一段""写个片段"这类模糊说法时，别当成硬约束——信息量超过片段就升一档，但停在短篇低段（1000–1500 字），不要往中篇膨胀；反过来，大纲里只有一个画面也不要硬撑成中篇。**超过一万字要拆**：江南自己的长篇架构也是弱项，宁可分成几个能独立成立的单元，每个单元单独走一遍本流程。

### 成文时的硬经验

- **长短句交错**：一段抒情长句后面跟一个短句（"很冷。""他没抬头。"）。文字的呼吸感来自这个落差。
- **通感**：五感互相借。声音可以像砂纸，光可以像融化的金子，难受可以像胸口塞了一团吸满水的棉花。至少把一处"很 X"的直白描写换成通感。
- **不说破的对话**：核心感情永远不通过台词说出来。两个人在诀别，嘴里聊的是天气和吃什么。
- **动作收束**：结尾给一个未完成的动作（张了张嘴、放下筷子、手停在门上），不要一句总结人生的独白。
- **留一道光**：再悲的结局，最后也留一点微小的暖意（一句吐槽、一碗还热着的面、路灯还亮着）。纯黑不是江南，那是另一种东西。

## 润色模式：已有文字 → 江南体

**只动质感，不动骨架。** 不改人物、不改事实、不新增情节、不替用户换结局。改完应该还是用户那篇东西，只是忽然有了呼吸和画面。

五步，按顺序过：

1. **去锚定**：抹掉会让读者一眼定位到某个年代的标记。"2021 年"→"那年"，"中关村大街"→"那条街"，具体品牌→泛称。目标是永恒感。原文本来就没有这类锚点就跳过——别为了走完流程，把普通名词也模糊成"某个地方"。
2. **冗余切除**：删掉不影响理解、删了反而更有力的东西——过度解释（"也就是说……"）、说教段、密集自嘲、泛化的情绪词（"感到非常难过"）、堆叠的连接词。判断口诀：**删了更短？删了更强？那就删。**
3. **句式注入**：抒情长句后面补短句；给硬话配软转折词；在关键处放一次"那时候他还不知道……"式的时间折叠。句式模板见 `references/style-dna.md`。
4. **通感激活**：扫描所有感官描写，把最直白的那几处升级成通感。
5. **软转折加固**：逐句检查硬话（宣言 / 否定 / 决断）后面有没有软词，缺了就补一个。

**润色的分寸**：控制标准不是字数，是**有没有加原文没有的信息**。原文本身有场景、有动作，改完应当不增或略减；原文只是梗概式的复述（通篇"他很后悔""这些年什么都没做"，指不出这一幕发生在哪、他在做什么），把它变成场景必然要变长，通常到原文的 2–3 倍——这是补画面，不是加戏。分不清时问自己：多出来的这一句，是原文信息的画面化，还是我新编的情节？后者一律删。

**路由补充**：原文如果是综述口吻的梗概，它其实更接近大纲——直接走成文模式，别硬按润色处理。判据就是上面那句：能不能指出"这一幕发生在哪儿、他在做什么"。

用户只说"润色一下"时，保持在原文的体裁和语气里，别顺手把它改写成小说。

## 交稿前自检

出稿前扫一遍，任何一条不过就回去改，别带病交付：

- [ ] 开头是画面，不是"很久以前 / 有一个少年 / 在这个世界上"
- [ ] 至少一处"宏大 × 微小"的反差
- [ ] 有一个具体信物，且它在结尾换了一种分量
- [ ] 没有"开心 / 难过 / 悲伤 / 感动"这类直接情绪词
- [ ] 没有说教、没有点题、没有总结人生的句子
- [ ] 结尾是一个动作 / 画面 / 声音，不是一个道理
- [ ] 长短句有落差，不是一路长句或一路短句
- [ ] 通感至少一处
- [ ] 润色模式下：事实、人物、情节与原文一致；多出来的字都是原文信息的画面化，没有新编的情节
- [ ] 只借文风：没有顺手塞进任何具体作品的专有名称或设定梗

同一项改两轮还过不了，就停下来，把稿子和没通过的点一起交给用户，让他定方向——不要在用户看不到的地方无限重写。

---

## 交付格式

- 默认中文。正文直接给，不要先复述一遍你打算怎么写。
- 段落 3–8 句（对话段可更短）；对话独立成段，动作神态附在对话后；场景切换用空行或 `***`。
- 用户没要求就别写文件，也别附"我用了哪些技法"的说明——他要是想看，会问。
- 用户可能要拿去改：如果他在意，可以在正文后附一张极简回执（选用的画面 / 代价 / 信物 / 篇幅），一行一个词就够。

## 诚实边界

**擅长**：中短篇情感叙事（200–10000 字）、人物出场 / 情感戏 / 告别 / 高潮片段、把已有文字改出江南味、序言后记类元叙事、画面感强的开场。

**不擅长**（别硬接，直接告诉用户）：长篇架构（>2 万字，拆成单元）、纯喜剧轻松向（最多"苦中作乐"）、学术 / 公文 / 新闻、女性第一人称（样本偏少）、完全脱离中文语境的翻译写作。

**关于"像不像"**：这个 skill 能做出高度相似的气质，但永远不等于江南本人。用户如果要求"以江南本人的名义发表""冒充他执笔"，说明界限并拒绝，改成原创致敬的写法。
