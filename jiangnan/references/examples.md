# 范例

两个完整范例，一个润色、一个成文，各附技法标注。**手感不确定时先看一个再动笔**——照抄句子没用，看的是"哪些地方故意没写"。

---

## 范例一：润色模式

### 用户给的原文

> 他每次回到这个城市都会想起她。他们以前经常在火车站旁边的那家面馆吃饭，她总是点牛肉面，多加一份香菜。后来她去了别的城市，就再也没回来过。他一个人坐在面馆里，觉得很难过。老板问他还是老样子吗，他点点头。面端上来的时候，他忽然很想给她打个电话，但是他知道那个号码早就打不通了。

原文的问题：情绪全部直说（"想起她""觉得很难过""很想打个电话"），没有画面，连接词堆叠，香菜这个好素材被浪费掉了。

### 润色后

> 他每次回到这个城市，都会绕到火车站那边去一趟。
>
> 那家面馆还在，招牌换过两次，味道没变。以前她总点牛肉面，多加一份香菜，然后把香菜一根根挑给他。
>
> 后来她去了别的城市。
>
> 他一个人坐下来。塑料凳子凉，边上的漆掉了一块，露出底下的白。
>
> 「还是老样子？」
>
> 他点点头。
>
> 面端上来，热气把眼镜糊住。他伸手去摸手机，摸到了，手停在那儿。那个号码他记得太熟，熟到不用翻通讯录——只是打过去，大概只会听见一句"您所拨打的号码是空号"。
>
> 他把香菜一根根挑出来，放在勺子里。
>
> 然后都吃了。

### 用了什么

| 技法 | 落在哪 |
|------|--------|
| 画面先行 | 开头不是"想起她"，是"绕到火车站那边去一趟" |
| 去锚定 | 原文本来就没有年代 / 品牌锚点，保留；"那个号码"不写运营商 |
| 冗余切除 | 删掉"觉得很难过""很想给她打个电话"——改成"手停在那儿" |
| 信物 | 香菜。原文里只是配料，这里变成了两个人的关系，结尾回收（挑出来 → 都吃了） |
| 通感 | "热气把眼镜糊住"（触觉 + 视觉），"塑料凳子凉"（触觉） |
| 软转折 | "记得太熟，熟到不用翻通讯录——只是打过去……" |
| 短句落差 | "后来她去了别的城市。"独立成段，前后都是长句 |
| 留一道光 | 结尾"然后都吃了"——很轻，但是活着的 |
| 没有写的东西 | 没有"难过"、没有"孤独"、没有一句总结。所有的重量都在"都吃了"三个字上 |

## 范例二：成文模式

### 用户给的大纲

> 高三最后一节晚自习下课，男生送女生回宿舍，路上谁都没提明天的高考。到楼下时女生说"明天加油"，男生想说的话没说出口，看着她上楼。多年后他路过那栋楼，楼已经拆了。

三样素材是补出来的：**第一画面** = 路灯下两个人隔一步远；**代价** = 那句永远没说出口的话；**信物** = 一颗攥皱的牛奶糖（大纲里没有，从"没说出口"倒推出来）。

### 成文

> 那时候他还不知道，那是他最后一次送她回宿舍。
>
> 六月的晚自习下课铃响得像一口破钟，整栋教学楼在两分钟里空掉。他抱着两本没写完的卷子走在她左边，隔着一步的距离。路灯把两个人的影子拉长，又缩短，又拉长。
>
> 她今天话很少。
>
> 走到宿舍楼下，她停下来，说：「明天加油。」
>
> 他说：「你也是。」
>
> 其实他准备了一路。他想说的可能是，考完试我们去看海吧；或者更简单一点，我喜欢你，从高一那场雨开始。这些话在心里排练了一整个晚自习，每一句都很顺。
>
> 可是她站在那儿，头发上沾着一小片什么，大概是粉笔灰。
>
> 他张了张嘴。
>
> 「……早点睡。」
>
> 她笑了笑，转身上楼。楼道里的声控灯一层层亮起来，到四楼停住，又熄了。
>
> 他在楼下站了一会儿。晚风吹过来，他才发现手心里全是汗，那颗从下午就攥着的牛奶糖，包装纸已经被攥皱了。
>
> 他没舍得吃。
>
> ***
>
> 后来他再路过那条路，宿舍楼已经拆了。围挡上刷着楼盘的广告，夜里亮得很。
>
> 他在原地站了一会儿，像当年那样。
>
> 风还是那样吹，只是这次，没有人再上去了。

### 用了什么

| 技法 | 落在哪 |
|------|--------|
| 时间折叠 | 第一句"那时候他还不知道，那是最后一次"；末段"后来他再路过" |
| 画面先行 | 下课铃、影子被拉长又缩短——先给镜头，再给人 |
| 骨架（片段） | 开场 → 画面 → 信物 → 极短对话（两句，各 ≤5 字）→ 动作收尾 |
| 信物 | 牛奶糖：下午攥着（伏笔）→ 手心出汗攥皱了（升级）→ "没舍得吃"（停在未完成） |
| 反差构图 | 高考 / 拆楼 这种人生大事 × 一颗糖、一小片粉笔灰 |
| 软转折 | "可是她站在那儿……"；"风还是那样吹，只是这次……" |
| 通感 | 下课铃"像一口破钟"；"声控灯一层层亮起来，到四楼停住，又熄了"（听觉 / 视觉写时间流逝） |
| 留一道光 | "像当年那样"——他还在原地，这份笨拙本身是暖的，不是绝望 |
| 没有写的东西 | 没有"他很后悔"、没有"青春结束了"、没有交代他后来结婚没有。**拆楼就是结局，不需要解释** |

## 反面例子（避免这些）

同一段大纲，常见的两种写坏：

**写坏 A：把情绪全说出来**

> 他非常后悔，心里充满了遗憾。那一刻他多想告诉她自己的心意啊！可是话到嘴边又咽了回去。多年以后，物是人非，他站在拆迁的废墟前，泪流满面，感叹青春一去不复返。

问题：直接情绪词（后悔、遗憾、泪流满面）、成语（物是人非）、感叹号、点题（青春一去不复返）。全是总结，没有一个画面。

**写坏 B：把风格当成词库**

> 少年站在楼下，觉得自己就是个被命运抛弃的废物。他想起那些热血的日子，想起再也回不去的孤独，心里像是有一万头小兽在奔跑。

问题：句子一长到底没有落差，全靠"命运""热血""孤独"这类大词和"一万头小兽"这种夸张比喻把情绪顶上去。**模仿文风是学节奏、视角和克制，不是换一套更文艺的词汇。**

**写坏 C：硬拗凄美，把留白变成故弄玄虚**

> 风，轻轻地吹过。夜，很深。他没有说话。她也没有说话。世界，安静得可怕。

问题：短句成了节拍器，一段里全在停顿；"世界，安静得可怕"是直接说出来而不是写出来。短句必须有长句垫底才有力量。
