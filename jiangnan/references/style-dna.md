## 一、句式库

每个模板配一个原创例句。**用的时候换掉里面的具体物，别换掉句子的落差结构**——落差结构才是江南。

### 1. 时间折叠（开场、回忆、跨时间收尾）

把当下放进一个未来的视角里，瞬间就有了缅怀感。

**可以只借结构、不填内容**：用"那时候他还不知道"起手，后文不必真的揭晓那个遗憾——但得有一个能让人回头想的悬念在。如果通篇没有任何东西值得回收，就老实换成画面开场，别硬拗这句。

```
模板：那时候{他}还不知道，{后来的遗憾}
模板：很多年以后{他}才明白，{当时那句没听懂的话}
模板：{当下的日常动作}。那时他还不知道，这是最后一次。
```

> 那时候他还不知道，这是最后一次走这条路。
> 很多年以后他才明白，那天她说"随便你"，其实是想让他挽留。

### 2. 反差构图（每一个高潮段落至少一次）

把最大的事和最小的事放进同一个句子里，中间不加解释。

```
模板：{宏大/灾难/宿命}。{他低头做的一件极小的事}。
模板：{整个世界都在崩塌}，而他只在意{一件微不足道的东西}。
```

> 楼在身后塌了。他蹲下来，把散在地上的橘子一个一个捡回袋子里。
> 全世界都在等他做决定，他在想那天早上的粥是不是糊了。

### 3. 代价陈述（最痛的事，用最平的调子说）

情绪不靠形容词，靠"说完了就没了"的冷静。

```
模板：{不可逆的事实}。这件事{他}知道。只是{一个日常的、忍不住的小动作}。
模板：{他}再也没{某个动作}了。不是因为不想，是因为{平静的原因}。
```

> 她不会回来了。这件事他知道。只是走在街上看到长头发的人，还是会多看一眼。
> 他后来再没打过那个电话。不是不想，是号码已经停机了。

### 4. 软转折（每 300 字至少一次）

硬话后面接软词，把宣言变成带颤抖的决心。

```
模板：{硬话}。哪怕{软话}。
模板：{决断}，只是{不舍}。
模板：{看起来平常的一句}。只是这一次，{没有人/不一样了}。
```

> 这次我不走了。哪怕前面什么都没有。
> 他答应得很干脆。只是挂电话的时候，手在抖。

### 5. 物哀定格（高潮或结尾，把情绪挪到物件上）

```
模板：就像{一件寻常物}，{承载着不寻常的分量}。
模板：{物件}还在原来的位置。{人}不在了。
```

> 就像那枚被捏扁的易拉罐，装过一个少年全部的勇气。
> 球鞋还摆在门口，鞋带是她系的。

### 6. 未完成收尾（结尾专用，不总结）

```
模板：他{动作}，然后{一个更小的动作}。
模板：{最后一句对话或一个声音}。{没有下文}。
```

> 他张了张嘴，最后只是把伞往她那边又推了推。
> 门上的铃铛响了一声。没有人进来。

### 7. Flag 式宣言（热血段落，先用来自嘲再用力）

```
模板：{不可能的事}？那又怎样。{更不可能的事}我也{做}。
模板：反正都是要{失去的}，那就{干脆用最笨的办法}。
```

> 输？那又怎样。反正我从来没赢过，再多输一次也没什么。
> 反正都要死，那就站着死。

## 二、通感升级对照表

润色第 4 步用：左边是"直白写法"，右边是"通感写法"。**不要全改**，挑最需要发力的两三处。

| 直白 | 通感升级 |
|------|---------|
| 声音很大 | 声音像有人在铁皮上拖椅子 |
| 很安静 | 安静得能听见灯管里电流的嗡嗡声 |
| 风很冷 | 风里有铁锈和雪的味道 |
| 灯光很亮 | 灯光白得像医院的走廊，照得人没有影子 |
| 心里很难受 | 胸口像塞了一团吸满水的棉花 |
| 他很累 | 眼皮沉得像挂了铅，抬一下都要借力气 |
| 她很漂亮 | 她笑起来的时候，眼角会先动一下（**不写漂亮，写那个只属于她的动作**） |
| 他很孤独 | 他一个人吃了三年晚饭，筷子都是一双 |
| 天很热 | 柏油路软了，鞋底踩上去发黏 |
| 雨下得很大 | 雨点砸在地上，像有人在楼下不停拍手 |
| 他紧张 | 他听见自己的心跳，撞得耳膜发疼 |

**判断标准**：通感要能还原成身体的感觉，不能只是"华丽的比喻"。写"忧伤像潮水"不算通感，算偷懒。

## 三、词表：慎用与常用

### 慎用 / 尽量不写

| 类型 | 例子 | 为什么 |
|------|------|--------|
| 成语（尤其是情绪类） | 泪如雨下、心如刀割、痛不欲生、百感交集 | 成语是别人嚼过的情绪，读者看到的是四个字，不是一个画面。除非故意解构它 |
| 直接情绪词 | 开心、难过、悲伤、痛苦、感动、幸福 | 说出来就廉价了；换成动作、身体反应、一个物件 |
| 抽象抒情词 | 命运、灵魂、永恒、青春、孤独（作为名词反复用） | 这些是主题词，不是描写；出现一次可以，撑起一段就空了 |
| 现代品牌 / 网络梗 | 具体手机型号、外卖平台、短视频热梗 | 会瞬间锚定年代，破坏永恒感（除非有明确的时代背景需求） |
| 学术 / 政治 / 公文术语 | 赋能、闭环、价值链、抓手 | 语域冲突，一秒破功 |
| 感叹号 | ！ | 江南的力量来自收着，不来自喊 |
| 转折词堆叠 | 因为……所以……虽然……但是…… | 砍掉一半，句子立刻有力 |

### 常用（用对了就有味道的小词）

- **软词**：只是、罢了、哪怕、不过、却、大概、好像、其实、原来、终于
- **具体物**：路灯、楼道、天台、便利店、泡面、橘子汽水、旧球鞋、耳机线、公交卡、课桌、粉笔灰
- **动作词**：攥、捏、蹭、按、抵、掖、张了张嘴、别过头、低下去
- **时间词**：那年、后来、很久以后、那时候、那天晚上

> ⚠️ 高频小词也要控量。"只是""那时候"在一段里连用三次，就从质感变成口头禅了。

## 四、体裁适配

江南味不是一套词，是一套节奏。换体裁时，**词要换，节奏内核不换**（缺失驱动 / 反差 / 信物）。

| 体裁 | 语域怎么调 | 优先用的内核 | 要小心的 |
|------|-----------|-------------|---------|
| 校园 | 白描、物件多、少形容词；对话带语气词 | 信物、时间折叠、日常反差 | 别写成怀旧散文，要有当下正在发生的事 |
| 奇幻 / 热血 | 允许长句铺陈宏大场面；战斗段落句子可以更短更硬 | 多重施压、一次性爆发、代价不可逆 | 别一味堆设定；重点是人物在宏大面前的反应 |
| 科幻 / 末日 | 冷静的科技名词 + 突然的日常细节 | 反差构图、彼岸映此岸 | 别写"实验室报告"式说明段 |
| 都市 / 职场 | 语域收一点，少用"命运"这类大词 | 缺失驱动、软转折、留一道光 | 容易写成鸡汤，结尾必须止于动作 |
| 序言 / 后记 | 可以第一人称对读者说话，允许元叙事 | 时间折叠、物哀 | 别真的去讲创作理念，要讲人 |
| 品牌文案 / 旁白 | 只保留画面和短句，砍掉所有抒情长句 | 反差、物哀 | 这是借气质，不是借文体，别写成小说 |

**不适用**：学术论文、公文、新闻稿、法律文书。用户要是拿这些来，直接说明这个 skill 帮不上。

## 五、常见跑偏与纠正

写"江南风"最容易掉的坑，照着自查：

| 跑偏 | 症状 | 纠正 |
|------|------|------|
| **短句癖** | 通篇"很冷。他没动。天黑了。" | 短句是长句的对手戏。先把长句写够，再在关键处砸一个短句 |
| **煽情堆叠** | 每一段都在爆情绪，读者麻木 | 加"呼吸孔"：一段平凡到无聊的日常，越平越好 |
| **成语代替描写** | 一句"泪如雨下"了事 | 换成一个身体动作：他背过身去，肩膀动了一下 |
| **提前点题** | 开头就写"这是关于孤独的故事" | 删掉。主题要读者自己撞上 |
| **强行圆满** | 结尾两人和好、事业成功 | 改成留白：赢下战斗但失去重要的东西 |
| **把风格当词库** | 满篇"少年""命运""孤独""热血"这类大词，或照搬某本书的口头禅 | 堆词不算模仿。文风是节奏、视角和克制，不是词汇表 |
| **翻译腔** | "他感到一种难以言喻的情绪涌上心头" | 中文叙事靠动作和物件，不靠心理名词。全部重写成身体反应 |
| **词汇过密** | 一段里三个比喻四个通感 | 通感是盐，一处到位即可；密了就是炫技 |
