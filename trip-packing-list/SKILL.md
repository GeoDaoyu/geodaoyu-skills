# 出差行李清单 Skill

用户每年都会出差，需要一份能反复复用的打包清单。这个 skill 的职责
**不是从零发明清单**，而是：拿用户自己的基础清单当骨架，按本次行程做增删，输出一份
能直接照着装箱的勾选清单。

**适用范围：目前只覆盖「驻场开发」这一类出差。** 用户明确说过现在只有这一种。
所以不要主动往清单里加见客户/做演示才需要的东西（正装、皮鞋、名片、演示转接头、翻页笔），
除非用户自己提到。

两条贯穿始终的原则：

- **基础清单是骨架，不是教条。** 每次行程不同，该补的补、该省的省，最后**直接给出结论清单就行**，
  不用解释为什么加、为什么减——用户要的是照着装箱，不是读一份变更说明。
- **现场购买是兜底，不是偷懒。** 盆、伞、牙膏这类到当地买更划算或更顺手的东西，不塞进箱子，
  单独列一节，提醒用户到了再买。

## 基础清单（用户底稿）

这是用户长期积累的版本。**除非用户明确说要改，否则每次都以它为起点**，不要凭空重写。

### 工作

- 电脑、键盘、鼠标、手托、支架
- 纸、笔
- 手机、耳机、充电器
- U 盘
- 背包、电脑包、腰包
- 眼镜盒、镜布

### 生活

- 外套、长袖、长裤
- 内衣、内裤、睡衣
- 袜子
- 脸帕、浴巾、洗面奶、刮胡刀
- 钥匙、身份证
- 茶包、卫生纸、水杯

### 现场购买

- 盆
- 伞（按需）
- 牙膏

## 用户的明确偏好

用户说过"以后都这样"的东西记在这里，**优先级高于上面所有规则**：不管清单模板、对照表还是易漏项
里怎么写，都不要再往清单里加下面这些。

- **不用充电宝，也很少带液体** —— 不要建议充电宝（备用数据线可以带），也不要写"随身液体
  ≤100ml""充电宝不能托运"这类安检提醒：这两样他本来就不带，提醒是纯噪音
- **不要问交通方式，也不要按交通方式调整清单** —— 飞机还是高铁不影响他带什么，
  用户从来没遇到过因为交通方式不同而带错东西的情况
- 不要"相比基础清单"这类变更说明段落，只给最终清单

用户以后再说"我不习惯 X"、"以后都加上 Y"，就往这一节里加一条，别只改这一次的输出。

## 工作流程

### 第 1 步：收齐行程信息

用户的实际调用方式通常就是四个字：**"我要出差"**。这时先给一张待填模板让他填，
**填完再出清单**——别在信息空白的情况下先甩一份通用清单。

四个字段，一个都不能少：

| 字段 | 用来决定什么 |
|---|---|
| 出发地 | **默认成都**；也决定哪些东西从家里带、哪些到了再买 |
| 到达地 | 天气、湿度、海拔、是否出国 |
| 出发时间 | 季节、衣服厚薄 |
| 回来时间 | 和出发时间一起算出在外几天 |

模板照抄这个格式，保持简短：

```
填一下这几项，我照着你的基础清单出一版：

- 出发地：成都
- 到达地：
- 出发时间：
- 回来时间：
```

规则：

- **唯一有默认值的是出发地（成都）。** 到达地和时间**都不许自己假设**——季节猜错，
  整份清单的衣服就是错的，那比多问一句的代价大得多
- **判断标准是"知不知道什么时候去"**：用户说了月份、具体日期，或"下个月""秋天"这类能推出
  季节的说法 → 不问，直接出清单；连这个都没有 → 出模板问。
  只说"去杭州出差 4 天"（有目的地、有天数、没时间）**也要问**，因为没法判断季节
- **天数是软要求**：知道什么时候去、但没说回来时间 → 按 4 天假设，在假设行里标注，
  不用为这个再问一轮
- **用户已经说过的字段要填好留在模板里**，别让他重复说一遍
- 用户明确说"就按老规矩"、"随便列一下" → 跳过模板，直接出清单
- 用户填完模板后，才是出清单的时候

为什么默认成都：用户常驻成都，绝大多数出差从成都出发。

### 第 1.5 步：算天数和季节

拿到出发/回来时间后：

- **在外天数 = 回来日期 − 出发日期**（也就是在外过几晚）。同一天来回按 1 天算
- 用户没给回来时间时，按 **4 天**假设，并在假设行里写清楚
- 日期区间原样写进清单标题，例如 `成都 → 杭州 · 10/20–10/24（4 晚）`，
  这样即使天数算得有歧义，用户一眼就能发现
- 只知道月份、不知道具体日期时，标题就写月份（`成都 → 杭州 · 10 月 · 约 4 天（4 晚）`），
  别编一个具体的日子出来
- 出发地和到达地都写进标题，别只写目的地——用户要能确认自己填的信息被吃进去了

### 第 2 步：在基础清单上做增删

对照下面的对照表逐条过一遍。命中多条时叠加。

| 情况 | 怎么调整 |
|---|---|
| 热天 / 目的地白天 ≥28°C | 外套改薄外套或防晒衣；加短袖、短裤、防晒霜、驱蚊、凉鞋 |
| 冷天 / 目的地 ≤5°C | 加羽绒服、保暖内衣、围巾手套、厚袜、润唇膏 |
| 春秋 / 10 月前后 | 基础清单里的外套+长袖+长裤正好，基本不用动 |
| 1–2 天 | 袜子内衣按 1 套备用即可，其余照旧 |
| 3–5 天 | 基础清单原样就是合适的量 |
| **≥7 天（驻场常见）** | 内衣袜子按"天数的一半再 +2"带，或计划中途洗；加洗衣皂/分装洗衣液、脏衣袋、备用鞋 |
| 南方 / 潮湿 | 多带一双鞋，或选速干衣物 |
| 干燥 / 高原 | 保湿、润唇膏、护手霜 |
| 出国 | 护照、签证、转换插头、境外流量/eSIM、少量外币现金 |
| 要报销 | 提醒留好发票、行程单 |

这张表里**故意没有"坐飞机 / 坐高铁"**：交通方式不影响带什么，不要按它调整清单，
也不要在清单末尾问用户是坐飞机还是高铁。

**驻场开发通常时间偏长**（1–2 周很常见），所以"≥7 天"那一行是重点，别按 4 天的量糊弄过去。

**默认偏保守**：拿不准某样东西要不要带时，保留它，但可以在清单里标一句"可省"。
少带一件东西的代价，通常比到了当地现买要大。

### 第 3 步：补易漏项

基础清单里没有、但出差时经常被忘的东西。**只挑跟本次行程相关的一两条**，不要整段灌输：

- 常备药：感冒药、肠胃药、创可贴、个人长期用药
- 备用数据线
- 拖鞋（酒店不提供时）、脏衣袋
- 牙刷牙膏（牙膏在"现场购买"里）
- 备用眼镜 / 隐形眼镜及护理液
- 工牌、门禁卡
- 口罩

加进去就是了，不用说明为什么加。

### 第 4 步：输出清单

在对话里直接给出 Markdown 勾选清单，用下面这个结构。**不要写文件**，除非用户明确要求存一份。

```markdown
# 出差行李清单 · <出发地> → <到达地> · <日期区间>（<N> 晚）

> <有假设时写一行，例如：按 10 月中旬、4 天、成都 → 杭州假设；驻场开发>

## 工作
- [ ] 电脑、电源
- [ ] 键盘、鼠标、手托、支架
- [ ] 纸、笔
- [ ] 手机、耳机、充电器
- [ ] U 盘
- [ ] 背包、电脑包、腰包
- [ ] 眼镜盒、镜布

## 生活
- [ ] 外套、长袖、长裤
- [ ] 内衣、内裤、睡衣
- [ ] 袜子
- [ ] 脸帕、浴巾、洗面奶、刮胡刀
- [ ] 钥匙、身份证
- [ ] 茶包、卫生纸、水杯

## 现场购买（到了再买，不用装箱）
- [ ] 盆
- [ ] 伞（按需）
- [ ] 牙膏
```

规则：

- 基础清单里的东西**逐条列出**，别用"等"、"之类"糊过去，勾选清单要能一条条勾
- 把同类小件合成一条（"键盘、鼠标、手托、支架"），但不要合并到看不清带了什么
- 现场购买那节注明"到了再买，不用装箱"，避免用户误以为要塞进箱子
- **只输出最终清单**，不要附带"相比基础清单"、"本次调整"这类变更说明段落
- 确实需要点一句的地方（比如某样东西可以不带走），在**那条条目后面**用括号带过就行，
  例如"电子纸（可省）"，不要另起一节

**清单末尾附一行问题**，把没问清的信息一次问完，方便用户一句话纠正：

> 如果这次的天数/目的地跟我假设的不一样，或者有别的安排，说一声我重出一版。

用户改主意时（"不带键盘了"、"这次去两周"）直接改清单重出一版，不要嘴上答应。

## 注意事项

- **不知道什么时候去就先出模板，不要先出清单。** 用户说"我要出差"时，他要的是那张四项待填模板。
  在没拿到"什么时候去"之前先甩一份通用清单，等于让他先读一份大概率不对的东西。
  反过来，只要他说了大概什么时候去，就别再问了，直接出清单——但**到达地和时间都不许自己编**
- **不要编造用户没有的需求**：不加泳衣、不加正装这类只有特定行程才用得上的东西
- **不要写变更说明**：不要出现"相比基础清单"、"本次增删"这类小节。用户要的是一份能直接照着装箱的
  清单，加什么减什么是你自己该判断的事，不需要向他汇报
- **基础清单是用户的资产**：用户说"以后都加上拖鞋"，就更新本文档里的基础清单，别只在这一次的输出里加
- **简短**：模板也好清单也好，话越少越好，用户要的是照着装箱，不是读一篇攻略
